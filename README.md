# Holy Integrals

This is an essay on a few integrals that I find incredibly interesting. Currently the essay contains:

$$
I_{0} = \int_{1}^{\sqrt{2}}{\frac{\arctan{\sqrt{2-x^2}}}{1+x^2}dx}
$$

$$
I_{1} = \int_{0}^{\infty}{\frac{\arctan^2{x}}{x^2 + 9}dx}
$$

$$
I_{2} = \int_{-1}^{1}{\frac{\arcsin{x} + 1}{x\sqrt{1-x^4}} \ln\left( \frac{(x^2 + 1)^{3/2} + x^3}{(x^2 + 1)^{3/2} - x^3} \right)dx}
$$
